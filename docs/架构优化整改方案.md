## 二、核心问题分析

### 2.1 边缘计算能力不足（优先级：P0）

#### 现状问题

**缺少本地数据处理能力**：
```java
// 当前：数据采集后直接存储，无本地处理
@Override
public void handlePropertyData(IotDevice device, JSONObject data) {
    // 直接存储到MySQL
    deviceDataService.save(deviceData);
    // 触发规则引擎
    ruleEngineService.triggerByDeviceData(device.getId(), data);
}
```

**缺少边缘分析能力**：
- 无数据聚合计算（平均值、最大值、趋势分析）
- 无异常检测算法
- 无本地AI推理能力

**缺少本地缓存策略**：
- 所有数据实时写MySQL，高频采集会导致性能瓶颈
- 无本地数据缓冲机制

#### 影响范围

- **性能影响**：1000设备×1秒采集周期 = 1000 TPS写入压力
- **功能缺失**：无法支持边缘侧实时分析和决策
- **网络依赖**：必须实时连接数据库，无离线工作能力

### 2.2 协议扩展机制硬编码（优先级：P0）

### 3.2 整改策略

#### 策略A：轻量化优先

**核心原则**：边缘网关必须轻量、快速、稳定

**具体措施**：
1. 移除未使用的InfluxDB容器
2. 使用嵌入式存储替代外部数据库
3. 使用高性能内存队列替代RabbitMQ
4. 优化连接池减少资源占用

#### 策略B：本地处理增强

**核心原则**：边缘侧完成数据处理，减少云端依赖

**具体措施**：
1. 增加本地数据聚合计算
2. 集成边缘AI推理能力
3. 实现本地数据缓存策略
4. 支持离线工作模式

#### 策略C：扩展性提升

**核心原则**：支持灵活扩展，降低定制成本

**具体措施**：
1. 实现协议驱动SPI机制
2. 支持外部JAR动态加载
3. 提供标准化扩展接口
4. 完善文档和示例

```java
// WindowAggregator.java
package vip.xiaonuo.iot.core.analytics;

import cn.hutool.core.collection.ConcurrentHashSet;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import java.util.*;
import java.util.concurrent.*;

/**
 * 数据窗口聚合器
 * 支持滑动窗口和滚动窗口统计
 */
@Slf4j
@Component
public class WindowAggregator {
    
    // 设备数据窗口缓存 <deviceId, <propertyKey, WindowData>>
    private final Map<String, Map<String, WindowData>> windowCache 
        = new ConcurrentHashMap<>();
    
    // 定时调度器
    private final ScheduledExecutorService scheduler 
        = Executors.newScheduledThreadPool(2);
    
    // 窗口大小（秒）
    private static final int WINDOW_SIZE = 60;
    
    @PostConstruct
    public void init() {
        // 每10秒计算一次窗口统计
        scheduler.scheduleAtFixedRate(this::calculateWindows, 10, 10, TimeUnit.SECONDS);
    }
    
    /**
     * 添加数据点
     */
    public void addDataPoint(String deviceId, String propertyKey, double value, long timestamp) {
        windowCache.computeIfAbsent(deviceId, k -> new ConcurrentHashMap<>())
                   .computeIfAbsent(propertyKey, k -> new WindowData())
                   .addPoint(value, timestamp);
    }
    
    /**
     * 计算窗口统计
     */
    private void calculateWindows() {
        long now = System.currentTimeMillis();
        long windowStart = now - WINDOW_SIZE * 1000;
        
        windowCache.forEach((deviceId, properties) -> {
            properties.forEach((propertyKey, windowData) -> {
                WindowStats stats = windowData.calculateStats(windowStart, now);
                
                log.debug("设备[{}]属性[{}]窗口统计: avg={}, max={}, min={}, count={}", 
                    deviceId, propertyKey, stats.getAvg(), stats.getMax(), 
                    stats.getMin(), stats.getCount());
                
                // 发布统计结果事件
                publishWindowStats(deviceId, propertyKey, stats);
                
                // 清理过期数据
                windowData.cleanup(windowStart);
            });
        });
    }
    
    /**
     * 发布窗口统计事件
     */
    private void publishWindowStats(String deviceId, String propertyKey, WindowStats stats) {
        // 可以触发规则引擎或存储统计结果
        // applicationEventPublisher.publishEvent(new WindowStatsEvent(deviceId, propertyKey, stats));
    }
    
    @PreDestroy
    public void shutdown() {
        scheduler.shutdown();
    }
    
    /**
     * 窗口数据
     */
    private static class WindowData {
        private final List<DataPoint> points = new CopyOnWriteArrayList<>();
        
        void addPoint(double value, long timestamp) {
            points.add(new DataPoint(value, timestamp));
        }
        
        WindowStats calculateStats(long startTime, long endTime) {
            List<Double> values = points.stream()
                .filter(p -> p.timestamp >= startTime && p.timestamp <= endTime)
                .map(p -> p.value)
                .toList();
            
            if (values.isEmpty()) {
                return new WindowStats(0, 0, 0, 0, 0);
            }
            
            double sum = values.stream().mapToDouble(Double::doubleValue).sum();
            double avg = sum / values.size();
            double max = values.stream().mapToDouble(Double::doubleValue).max().orElse(0);
            double min = values.stream().mapToDouble(Double::doubleValue).min().orElse(0);
            
            return new WindowStats(avg, max, min, sum, values.size());
        }
        
        void cleanup(long beforeTime) {
            points.removeIf(p -> p.timestamp < beforeTime);
        }
    }
    
    /**
     * 数据点
     */
    private static class DataPoint {
        double value;
        long timestamp;
        
        DataPoint(double value, long timestamp) {
            this.value = value;
            this.timestamp = timestamp;
        }
    }
    
    /**
     * 窗口统计结果
     */
    @Data
    public static class WindowStats {
        private final double avg;
        private final double max;
        private final double min;
        private final double sum;
        private final long count;
    }
}
```

#### 4.1.2 异常检测算法

**实现方案**：基于3σ原则的异常检测

```java
// AnomalyDetector.java
package vip.xiaonuo.iot.core.analytics;

import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import java.util.List;

/**
 * 异常检测器
 */
@Slf4j
@Component
public class AnomalyDetector {
    
    /**
     * 基于3σ原则检测异常
     * @param values 历史数据点
     * @param currentValue 当前值
     * @return 是否异常
     */
    public boolean detectAnomaly(List<Double> values, double currentValue) {
        if (values.size() < 10) {
            return false; // 数据点太少，无法判断
        }
        
        // 计算均值
        double mean = values.stream()
            .mapToDouble(Double::doubleValue)
            .average()
            .orElse(0);
        
        // 计算标准差
        double variance = values.stream()
            .mapToDouble(v -> Math.pow(v - mean, 2))
            .average()
            .orElse(0);
        double stdDev = Math.sqrt(variance);
        
        // 3σ原则：超出3倍标准差为异常
        double lowerBound = mean - 3 * stdDev;
        double upperBound = mean + 3 * stdDev;
        
        boolean isAnomaly = currentValue < lowerBound || currentValue > upperBound;
        
        if (isAnomaly) {
            log.warn("检测到异常值: current={}, mean={}, stdDev={}, bounds=[{}, {}]",
                currentValue, mean, stdDev, lowerBound, upperBound);
        }
        
        return isAnomaly;
    }
    
    /**
     * 基于IQR的异常检测（更鲁棒）
     */
    public boolean detectAnomalyByIQR(List<Double> values, double currentValue) {
        if (values.size() < 10) {
            return false;
        }
        
        List<Double> sorted = values.stream().sorted().toList();
        int size = sorted.size();
        
        // 计算四分位数
        double q1 = sorted.get(size / 4);
        double q3 = sorted.get(size * 3 / 4);
        double iqr = q3 - q1;
        
        // IQR异常边界
        double lowerBound = q1 - 1.5 * iqr;
        double upperBound = q3 + 1.5 * iqr;
        
        return currentValue < lowerBound || currentValue > upperBound;
    }
}
```

```java
     */

        env = OrtEnvironment.getEnvironment();
        OrtSession.SessionOptions options = new OrtSession.SessionOptions();
        options.setOptimizationLevel(OrtSession.SessionOptions.OptLevel.ALL_OPT);
        
        session = env.createSession(modelPath, options);
        log.info("ONNX模型加载成功: {}", modelPath);
    }
    
    /**
     * 执行推理
     * @param inputData 输入数据（设备特征向量）
     * @return 推理结果
     */
    public float[] inference(float[] inputData) throws OrtException {
        if (session == null) {
            throw new IllegalStateException("模型未加载");
        }
        
        // 创建输入Tensor
        long[] shape = {1, inputData.length};
        OnnxTensor inputTensor = OnnxTensor.createTensor(
            env, 
            FloatBuffer.wrap(inputData), 
            shape
        );
        
        // 执行推理
        Map<String, OnnxTensor> inputs = Map.of("input", inputTensor);
        OrtSession.Result result = session.run(inputs);
        
        // 获取输出
        float[][] output = (float[][]) result.get(0).getValue();
        
        inputTensor.close();
        result.close();
        
        return output[0];
    }
    
    /**
     * 示例：设备故障预测
     */
    public double predictFailureProbability(Map<String, Double> deviceMetrics) {
        try {
            // 将设备指标转换为特征向量
            float[] features = extractFeatures(deviceMetrics);
            
            // 执行推理
            float[] prediction = inference(features);
            
            // 返回故障概率
            return prediction[0];
        } catch (Exception e) {
            log.error("AI推理失败", e);
            return 0.0;
        }
    }
    
    private float[] extractFeatures(Map<String, Double> metrics) {
        // 特征工程：提取关键指标
        return new float[] {
            metrics.getOrDefault("temperature", 0.0).floatValue(),
            metrics.getOrDefault("vibration", 0.0).floatValue(),
            metrics.getOrDefault("current", 0.0).floatValue(),
            // ... 其他特征
        };
    }
}
```

```java
    /**
     * 从JAR文件加载驱动
     * @param jarFile 驱动JAR文件
     */
    public void loadFromJar(File jarFile) {
        if (!jarFile.exists() || !jarFile.getName().endsWith(".jar")) {
            throw new IllegalArgumentException("无效的JAR文件: " + jarFile);
        }
        
        try {
            // 创建独立的类加载器
            URLClassLoader classLoader = new URLClassLoader(
                new URL[]{jarFile.toURI().toURL()},
                getClass().getClassLoader()
            );
            
            // 使用ServiceLoader加载驱动
            ServiceLoader<DriverProvider> loader = ServiceLoader.load(
                DriverProvider.class, 
                classLoader
            );
            
            for (DriverProvider provider : loader) {
                driverSpiLoader.registerDriver(provider);
                log.info("从JAR加载驱动: jar={}, type={}", 
                    jarFile.getName(), provider.getDriverType());
            }
            
        } catch (Exception e) {
            log.error("加载外部驱动失败: {}", jarFile, e);
            throw new RuntimeException("加载驱动失败", e);
        }
    }
    
    /**
     * 扫描目录加载所有驱动JAR
     */
    public void loadFromDirectory(String directory) {
        File dir = new File(directory);
        if (!dir.exists() || !dir.isDirectory()) {
            log.warn("驱动目录不存在: {}", directory);
            return;
        }
        
        File[] jarFiles = dir.listFiles((d, name) -> name.endsWith(".jar"));
        if (jarFiles == null || jarFiles.length == 0) {
            log.info("驱动目录为空: {}", directory);
            return;
        }
        
        for (File jarFile : jarFiles) {
            try {
                loadFromJar(jarFile);
            } catch (Exception e) {
                log.error("加载驱动JAR失败: {}", jarFile.getName(), e);
            }
        }
    }
```

```java
// TimeSeriesStorageService.java
package vip.xiaonuo.iot.core.storage;

import cn.hutool.core.date.DateUtil;
import lombok.extern.slf4j.Slf4j;
import net.openhft.chronicle.map.ChronicleMap;
import org.mapdb.DB;
import org.mapdb.DBMaker;
import org.mapdb.Serializer;
import org.springframework.stereotype.Service;

import javax.annotation.PostConstruct;
import javax.annotation.PreDestroy;
import javax.annotation.Resource;
import java.io.File;
import java.io.IOException;
import java.util.*;
import java.util.concurrent.*;

/**
 * 时序数据分层存储服务
 * 
 * 架构设计：
 * - 热数据（最近24小时）：Chronicle Map（内存映射）
 * - 温数据（7天内）：MapDB（文件存储）
 * - 冷数据（>7天）：MySQL（归档）
 */
@Slf4j
@Service
public class TimeSeriesStorageService {
    
    @Resource
    private IotDeviceDataService deviceDataService;
    
    // 热数据存储（内存映射）
    private ChronicleMap<String, DeviceDataPoint> hotDataMap;
    
    // 温数据存储（文件数据库）
    private DB warmDataDB;
    private ConcurrentMap<String, List<DeviceDataPoint>> warmDataMap;
    
    // 定时任务调度器
    private final ScheduledExecutorService scheduler 
        = Executors.newScheduledThreadPool(2);
    
    // 时间阈值（毫秒）
    private static final long HOT_DATA_THRESHOLD = 24 * 3600 * 1000L;  // 24小时
    private static final long WARM_DATA_THRESHOLD = 7 * 24 * 3600 * 1000L;  // 7天
    
    @PostConstruct
    public void init() throws IOException {
        // 初始化热数据存储
        File hotDataFile = new File("data/hot_timeseries.dat");
        hotDataFile.getParentFile().mkdirs();
        
        hotDataMap = ChronicleMap
            .of(String.class, DeviceDataPoint.class)
            .name("hot-data-map")
            .entries(1_000_000)  // 支持100万数据点
            .averageKey("device_123456:temperature")
            .averageValue(new DeviceDataPoint("", "", 0.0, 0L))
            .createPersistedTo(hotDataFile);
        
        log.info("热数据存储初始化完成：{}", hotDataFile.getAbsolutePath());
        
        // 初始化温数据存储
        warmDataDB = DBMaker.fileDB("data/warm_timeseries.db")
            .fileMmapEnable()
            .transactionEnable()
            .make();
        
        warmDataMap = warmDataDB.hashMap("warm-data")
            .keySerializer(Serializer.STRING)
            .valueSerializer(Serializer.JAVA)
            .createOrOpen();
        
        log.info("温数据存储初始化完成");
        
        // 启动数据分层任务
        scheduler.scheduleAtFixedRate(this::tieringData, 1, 10, TimeUnit.MINUTES);
        
        // 启动数据归档任务
        scheduler.scheduleAtFixedRate(this::archiveData, 1, 60, TimeUnit.MINUTES);
    }
    
    /**
     * 写入数据点
     */
    public void write(String deviceId, String propertyKey, double value, long timestamp) {
        String key = buildKey(deviceId, propertyKey, timestamp);
        DeviceDataPoint dataPoint = new DeviceDataPoint(deviceId, propertyKey, value, timestamp);
        
        // 写入热数据层
        hotDataMap.put(key, dataPoint);
    }
    
    /**
     * 查询数据（自动选择存储层）
     */
    public List<DeviceDataPoint> query(String deviceId, String propertyKey, 
                                       long startTime, long endTime) {
        List<DeviceDataPoint> result = new ArrayList<>();
        long now = System.currentTimeMillis();
        
        // 1. 查询热数据层
        if (endTime >= now - HOT_DATA_THRESHOLD) {
            result.addAll(queryHotData(deviceId, propertyKey, startTime, endTime));
        }
        
        // 2. 查询温数据层
        if (startTime < now - HOT_DATA_THRESHOLD && endTime >= now - WARM_DATA_THRESHOLD) {
            result.addAll(queryWarmData(deviceId, propertyKey, startTime, endTime));
        }
        
        // 3. 查询冷数据层（MySQL）
        if (startTime < now - WARM_DATA_THRESHOLD) {
            result.addAll(queryColdData(deviceId, propertyKey, startTime, endTime));
        }
        
        // 按时间排序
        result.sort(Comparator.comparingLong(DeviceDataPoint::getTimestamp));
        
        return result;
    }
    
    /**
     * 查询热数据
     */
    private List<DeviceDataPoint> queryHotData(String deviceId, String propertyKey, 
                                               long startTime, long endTime) {
        List<DeviceDataPoint> result = new ArrayList<>();
        
        hotDataMap.forEach((key, dataPoint) -> {
            if (dataPoint.getDeviceId().equals(deviceId)
                && dataPoint.getPropertyKey().equals(propertyKey)
                && dataPoint.getTimestamp() >= startTime
                && dataPoint.getTimestamp() <= endTime) {
                result.add(dataPoint);
            }
        });
        
        return result;
    }
    
    /**
     * 查询温数据
     */
    private List<DeviceDataPoint> queryWarmData(String deviceId, String propertyKey, 
                                                long startTime, long endTime) {
        String mapKey = buildMapKey(deviceId, propertyKey);
        List<DeviceDataPoint> dataPoints = warmDataMap.get(mapKey);
        
        if (dataPoints == null) {
            return Collections.emptyList();
        }
        
        return dataPoints.stream()
            .filter(dp -> dp.getTimestamp() >= startTime && dp.getTimestamp() <= endTime)
            .toList();
    }
    
    /**
     * 查询冷数据（MySQL）
     */
    private List<DeviceDataPoint> queryColdData(String deviceId, String propertyKey, 
                                                long startTime, long endTime) {
        // 调用MySQL服务查询
        LambdaQueryWrapper<IotDeviceData> queryWrapper = new LambdaQueryWrapper<>();
        queryWrapper.eq(IotDeviceData::getDeviceId, deviceId)
                   .eq(IotDeviceData::getPropertyKey, propertyKey)
                   .between(IotDeviceData::getCollectTime, 
                           new Date(startTime), new Date(endTime));
        
        List<IotDeviceData> dataList = deviceDataService.list(queryWrapper);
        
        return dataList.stream()
            .map(d -> new DeviceDataPoint(
                d.getDeviceId(),
                d.getPropertyKey(),
                Double.parseDouble(d.getPropertyValue()),
                d.getCollectTime().getTime()
            ))
            .toList();
    }
    
    /**
     * 数据分层任务（热 -> 温）
     */
    private void tieringData() {
        try {
            long now = System.currentTimeMillis();
            long hotThreshold = now - HOT_DATA_THRESHOLD;
            
            List<String> keysToMove = new ArrayList<>();
            
            // 找出需要移动的热数据
            hotDataMap.forEach((key, dataPoint) -> {
                if (dataPoint.getTimestamp() < hotThreshold) {
                    keysToMove.add(key);
                }
            });
            
            // 移动到温数据层
            for (String key : keysToMove) {
                DeviceDataPoint dataPoint = hotDataMap.remove(key);
                if (dataPoint != null) {
                    String mapKey = buildMapKey(dataPoint.getDeviceId(), dataPoint.getPropertyKey());
                    warmDataMap.compute(mapKey, (k, list) -> {
                        if (list == null) {
                            list = new ArrayList<>();
                        }
                        list.add(dataPoint);
                        return list;
                    });
                }
            }
            
            if (!keysToMove.isEmpty()) {
                warmDataDB.commit();
                log.info("数据分层完成：热->温 {}条", keysToMove.size());
            }
            
        } catch (Exception e) {
            log.error("数据分层失败", e);
        }
    }
    
    /**
     * 数据归档任务（温 -> 冷）
     */
    private void archiveData() {
        try {
            long now = System.currentTimeMillis();
            long warmThreshold = now - WARM_DATA_THRESHOLD;
            
            List<IotDeviceData> archiveList = new ArrayList<>();
            List<String> keysToRemove = new ArrayList<>();
            
            // 找出需要归档的温数据
            warmDataMap.forEach((key, dataPoints) -> {
                Iterator<DeviceDataPoint> iterator = dataPoints.iterator();
                while (iterator.hasNext()) {
                    DeviceDataPoint dp = iterator.next();
                    if (dp.getTimestamp() < warmThreshold) {
                        // 转换为MySQL实体
                        IotDeviceData data = new IotDeviceData();
                        data.setDeviceId(dp.getDeviceId());
                        data.setPropertyKey(dp.getPropertyKey());
                        data.setPropertyValue(String.valueOf(dp.getValue()));
                        data.setCollectTime(new Date(dp.getTimestamp()));
                        data.setCreateTime(new Date());
                        
                        archiveList.add(data);
                        iterator.remove();
                    }
                }
                
                if (dataPoints.isEmpty()) {
                    keysToRemove.add(key);
                }
            });
            
            // 批量归档到MySQL
            if (!archiveList.isEmpty()) {
                deviceDataService.saveBatch(archiveList);
                
                // 清理空键
                keysToRemove.forEach(warmDataMap::remove);
                warmDataDB.commit();
                
                log.info("数据归档完成：温->冷 {}条", archiveList.size());
            }
            
        } catch (Exception e) {
            log.error("数据归档失败", e);
        }
    }
    
    /**
     * 构建存储Key
     */
    private String buildKey(String deviceId, String propertyKey, long timestamp) {
        return deviceId + ":" + propertyKey + ":" + timestamp;
    }
    
    /**
     * 构建Map Key
     */
    private String buildMapKey(String deviceId, String propertyKey) {
        return deviceId + ":" + propertyKey;
    }
    
    @PreDestroy
    public void shutdown() {
        scheduler.shutdown();
        
        if (hotDataMap != null) {
            hotDataMap.close();
        }
        
        if (warmDataDB != null) {
            warmDataDB.close();
        }
        
        log.info("时序数据存储服务已关闭");
    }
    
    /**
     * 数据点实体
     */
    @Data
    @AllArgsConstructor
    @NoArgsConstructor
    public static class DeviceDataPoint implements Serializable {
        private String deviceId;
        private String propertyKey;
        private double value;
        private long timestamp;
    }
}
```

```java
/**

@Slf4j
@Component
public class ChronicleMessageQueue {
    
    private ChronicleQueue deviceQueue;
    private ChronicleQueue ruleQueue;
    
    private ExecutorService executorService;
    
    @PostConstruct
    public void init() {
        // 初始化设备消息队列
        deviceQueue = SingleChronicleQueueBuilder
            .binary("data/queue/device")
            .rollCycle(RollCycles.DAILY)  // 每天滚动一次

            .binary("data/queue/rule")
            .rollCycle(RollCycles.DAILY)
            .build();

        executorService = Executors.newFixedThreadPool(4);
        executorService.submit(this::consumeDeviceMessages);
        executorService.submit(this::consumeRuleMessages);
    }
    
    /**
     * 发送设备消息

        try {
            ExcerptAppender appender = deviceQueue.acquireAppender();
            appender.writeDocument(w -> {
                w.write("deviceId").text(message.getDeviceId());
                w.write("data").text(message.getData().toString());
                w.write("timestamp").int64(message.getTimestamp());
            });
            return true;
        } catch (Exception e) {
            log.error("发送设备消息失败", e);
            return false;
        }
    }
    
    /**
     * 发送规则触发消息
     */
    public boolean sendRuleTrigger(String ruleId, JSONObject triggerData) {
        try {
            ExcerptAppender appender = ruleQueue.acquireAppender();
            appender.writeDocument(w -> {
                w.write("ruleId").text(ruleId);
                w.write("triggerData").text(triggerData.toString());
                w.write("timestamp").int64(System.currentTimeMillis());
            });
            return true;
        } catch (Exception e) {
            log.error("发送规则消息失败", e);
            return false;
        }
    }
    
    /**
     * 消费设备消息
     */
    private void consumeDeviceMessages() {
        ExcerptTailer tailer = deviceQueue.createTailer();
        
        while (!Thread.currentThread().isInterrupted()) {
            try {
                boolean hasMessage = tailer.readDocument(w -> {
                    String deviceId = w.read("deviceId").text();
                    String dataStr = w.read("data").text();
                    long timestamp = w.read("timestamp").int64();

                }
            } catch (InterruptedException e) {
                Thread.currentThread().interrupt();
                break;
            } catch (Exception e) {
                log.error("消费设备消息异常", e);
            }
        }
    }
    
    /**
     * 消费规则消息

    private void consumeRuleMessages() {
```

```java
// ModbusConnectionPool.java
package vip.xiaonuo.iot.core.protocol.modbus;

import com.serotonin.modbus4j.ModbusMaster;
import com.serotonin.modbus4j.ModbusFactory;
import com.serotonin.modbus4j.ip.IpParameters;
import lombok.extern.slf4j.Slf4j;
import org.apache.commons.pool2.BasePooledObjectFactory;
import org.apache.commons.pool2.PooledObject;
import org.apache.commons.pool2.impl.DefaultPooledObject;
import org.apache.commons.pool2.impl.GenericObjectPool;
import org.apache.commons.pool2.impl.GenericObjectPoolConfig;

/**
 * Modbus连接池
 */
@Slf4j
public class ModbusConnectionPool {
    
    private final GenericObjectPool<ModbusMaster> pool;
    private final String host;
    private final int port;
    
    public ModbusConnectionPool(String host, int port) {
        this.host = host;
        this.port = port;
        
        // 连接池配置
        GenericObjectPoolConfig<ModbusMaster> config = new GenericObjectPoolConfig<>();
        config.setMaxTotal(50);  // 最大连接数
        config.setMaxIdle(20);   // 最大空闲连接
        config.setMinIdle(5);    // 最小空闲连接
        config.setTestOnBorrow(true);  // 借用时测试
        config.setTestOnReturn(true);  // 归还时测试
        config.setTestWhileIdle(true); // 空闲时测试
        config.setTimeBetweenEvictionRunsMillis(60000);  // 空闲检测周期
        config.setMinEvictableIdleTimeMillis(300000);    // 最小空闲时间
        
        // 创建连接池
        pool = new GenericObjectPool<>(
            new ModbusMasterFactory(host, port),
            config
        );
        
        log.info("Modbus连接池初始化: host={}, port={}, maxTotal={}", host, port, config.getMaxTotal());
    }
    
    /**
     * 获取连接
     */
    public ModbusMaster borrowConnection() throws Exception {
        return pool.borrowObject();
    }
    
    /**
     * 归还连接
     */
    public void returnConnection(ModbusMaster master) {
        pool.returnObject(master);
    }
    
    /**
     * 关闭连接池
     */
    public void close() {
        pool.close();
        log.info("Modbus连接池已关闭: host={}, port={}", host, port);
    }
    
    /**
     * 获取连接池状态
     */
    public PoolStatus getStatus() {
        return new PoolStatus(
            pool.getNumActive(),
            pool.getNumIdle(),
            pool.getMaxTotal()
        );
    }
    
    /**
     * Modbus连接工厂
     */
    private static class ModbusMasterFactory extends BasePooledObjectFactory<ModbusMaster> {
        private final String host;
        private final int port;
        
        public ModbusMasterFactory(String host, int port) {
            this.host = host;
            this.port = port;
        }
        
        @Override
        public ModbusMaster create() throws Exception {
            ModbusFactory factory = new ModbusFactory();
            IpParameters params = new IpParameters();
            params.setHost(host);
            params.setPort(port);
            params.setEncapsulated(true);
            
            ModbusMaster master = factory.createTcpMaster(params, true);
            master.setTimeout(3000);
            master.setRetries(2);
            master.init();
            
            log.debug("创建Modbus连接: {}:{}", host, port);
            return master;
        }
        
        @Override
        public PooledObject<ModbusMaster> wrap(ModbusMaster master) {
            return new DefaultPooledObject<>(master);
        }
        
        @Override
        public void destroyObject(PooledObject<ModbusMaster> p) {
            ModbusMaster master = p.getObject();
            if (master != null) {
                master.destroy();
                log.debug("销毁Modbus连接: {}:{}", host, port);
            }
        }
        
        @Override
        public boolean validateObject(PooledObject<ModbusMaster> p) {
            // 连接健康检查
            ModbusMaster master = p.getObject();
            try {
                // 发送心跳测试
                return master != null && master.isInitialized();
            } catch (Exception e) {
                return false;
            }
        }
    }
    
    /**
     * 连接池状态
     */
    @Data
    @AllArgsConstructor
    public static class PoolStatus {
        private int activeConnections;
        private int idleConnections;
        private int maxConnections;
    }
}
```

```java
// DeviceAuthenticator.java
package vip.xiaonuo.iot.core.security;

import cn.hutool.core.util.IdUtil;
import cn.hutool.crypto.SecureUtil;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;

import java.util.Map;
import java.util.concurrent.ConcurrentHashMap;
import java.util.concurrent.TimeUnit;

/**
 * 设备认证器
 */
@Slf4j
@Component
public class DeviceAuthenticator {
    
    // 设备Token缓存 <deviceKey, TokenInfo>
    private final Map<String, TokenInfo> tokenCache = new ConcurrentHashMap<>();
    
    // Token有效期（小时）
    private static final long TOKEN_EXPIRE_HOURS = 24;
    
    /**
     * 生成设备Token
     */
    public String generateToken(String deviceKey, String deviceSecret) {
        // 验证设备密钥
        if (!validateDeviceSecret(deviceKey, deviceSecret)) {
            throw new SecurityException("设备密钥验证失败");
        }
        
        // 生成Token
        String token = IdUtil.simpleUUID();
        long expireTime = System.currentTimeMillis() + TimeUnit.HOURS.toMillis(TOKEN_EXPIRE_HOURS);
        
        // 缓存Token
        tokenCache.put(deviceKey, new TokenInfo(token, expireTime));
        
        log.info("设备Token生成: deviceKey={}", deviceKey);
        return token;
    }
    
    /**
     * 验证设备Token
     */
    public boolean validateToken(String deviceKey, String token) {
        TokenInfo tokenInfo = tokenCache.get(deviceKey);
        
        if (tokenInfo == null) {
            log.warn("设备Token不存在: deviceKey={}", deviceKey);
            return false;
        }
        
        // 检查Token是否过期
        if (System.currentTimeMillis() > tokenInfo.expireTime) {
            tokenCache.remove(deviceKey);
            log.warn("设备Token已过期: deviceKey={}", deviceKey);
            return false;
        }
        
        // 验证Token
        boolean valid = tokenInfo.token.equals(token);
        
        if (!valid) {
            log.warn("设备Token验证失败: deviceKey={}", deviceKey);
        }
        
        return valid;
    }
    
    /**
     * 撤销设备Token
     */
    public void revokeToken(String deviceKey) {
        tokenCache.remove(deviceKey);
        log.info("设备Token已撤销: deviceKey={}", deviceKey);
```

```java
package vip.xiaonuo.iot.core.driver.impl;

import vip.xiaonuo.iot.core.driver.DriverConfig;

import javax.net.ssl.SSLContext;
import javax.net.ssl.TrustManagerFactory;
import java.io.FileInputStream;
import java.security.KeyStore;

/**
 * 安全Modbus TCP驱动（支持TLS）
 */
public class SecureModbusTcpDriver extends ModbusTcpDriver {
    
    public SecureModbusTcpDriver(DriverConfig config) {
        super(config);
    }
    
    @Override
    protected ModbusMaster createMaster(IpParameters params) throws Exception {
        // 启用TLS加密
        if (config.getBoolean("enableTls", false)) {
            SSLContext sslContext = createSSLContext();
            // 注：modbus4j默认不支持TLS，需要自定义实现
            // 或使用支持TLS的Modbus库
        }
        
        return super.createMaster(params);
    }
    
    /**
     * 创建SSL上下文
     */
    private SSLContext createSSLContext() throws Exception {
        KeyStore keyStore = KeyStore.getInstance("JKS");
        keyStore.load(
            new FileInputStream("config/keystore.jks"),
            "password".toCharArray()
        );
        
        TrustManagerFactory tmf = TrustManagerFactory.getInstance(
            TrustManagerFactory.getDefaultAlgorithm()
        );
        tmf.init(keyStore);
        
        SSLContext sslContext = SSLContext.getInstance("TLS");
        sslContext.init(null, tmf.getTrustManagers(), null);
        
        return sslContext;
    }
}
```
